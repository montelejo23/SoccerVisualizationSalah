# Soccer Data Visualization
This repository contains a Python notebook designed to analyze and visualize soccer performance data. The notebook provides insights into player statistics and performance metrics using advanced visualizations. 

## Features
- Data preprocessing: Cleaning and transforming positional and performance data.
- Visualizations: Leveraging mplsoccer to create soccer field plots and heatmaps.
- Performance metrics: Calculating key statistics like total shots, goals, and expected goals (xG).

## Workflow

Data Loading and Cleaning:
  - Load the soccer performance dataset.
  - Transform positional data.

Metric Calculations:
  - Compute key statistics like total shots, goals, and xG.
  - Calculate additional metrics like average distance for shots.

Visualizations:
  - Use mplsoccer to create heatmaps and field visualizations.
  - Highlight key insights through annotated plots.
    
## Outputs
Soccer field visualizations showing shot locations and heatmaps.
Statistical summaries of player performance.
